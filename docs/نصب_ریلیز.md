# نصب نسخه ریلیز

## خطای App not installed

معمولاً به این دلایل است:

1. **نسخه debug قبلاً نصب است** (امضای متفاوت)
   - اپ قدیمی را کامل حذف کنید، بعد APK ریلیز را نصب کنید.

2. **keystore.properties در ریشه پروژه نبود** و APK با کلید debug ساخته شده
   - فایل‌های `ptt-release.jks` و `keystore.properties` را در ریشه پروژه بگذارید
   - دوباره `assembleRelease` بزنید

3. **نصب از منبع ناشناس** در تنظیمات گوشی فعال نیست

## ساخت APK برای کافه‌بازار

```
gradlew.bat :app:assembleRelease
```

مسیر خروجی:
`app/build/outputs/apk/release/app-release.apk`

قبل از آپلود روی بازار، روی یک گوشی تمیز (بدون نسخه قبلی اپ) تست نصب کنید.
